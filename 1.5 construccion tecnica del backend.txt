WebSocket frontend
Conexión

  const data = JSON.parse(event.data);
}

TIMER

MUY importante.

NO usar timer independiente.

El backend manda:

questionStartTime
Frontend calcula:

visual solamente.

PROBLEMA típico
Lag visual.
Solución:

actualizar timer:

cada 100ms

No cada segundo.
